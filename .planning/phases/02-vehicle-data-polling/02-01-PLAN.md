    Capability definitions:

    1. **measure_range.json** — `type: "number"`, title "Range", units "km" (default — will be updated dynamically at runtime for mi/km per user decision), min 0, max 700, step 1, decimals 0

    2. **charging_status.json** — `type: "enum"`, title "Charging", values: `[{ id: "Disconnected", title: "Disconnected" }, { id: "Charging", title: "Charging" }, { id: "Stopped", title: "Stopped" }, { id: "Complete", title: "Complete" }, { id: "NoPower", title: "No Power" }]`

    3. **vehicle_state_status.json** — `type: "enum"`, title "Vehicle", values: `[{ id: "Awake", title: "Awake" }, { id: "Asleep", title: "Asleep" }, { id: "Offline", title: "Offline" }]`. Per user decision: distinct states for Asleep (normal) vs Offline (problem).

    4-7. **measure_tire_pressure_fl/fr/rl/rr.json** — `type: "number"`, titles "Tire FL"/"Tire FR"/"Tire RL"/"Tire RR", units "bar" (default — dynamically updated for bar/psi per user decision), min 0, max 5 (bar) or appropriate, step 0.1, decimals 1. Per user decision: four separate capabilities, one per wheel.

    8. **measure_odometer.json** — `type: "number"`, title "Odometer", units "km" (default — dynamically updated for km/mi per user decision), min 0, max 999999, step 1, decimals 0

    9. **measure_latitude.json** — `type: "number"`, title "Latitude", min -90, max 90, step 0.000001, decimals 6. No units string.

    10. **measure_longitude.json** — `type: "number"`, title "Longitude", min -180, max 180, step 0.000001, decimals 6. No units string.

    11. **software_update.json** — `type: "string"`, title "Software", getable: true, setable: false, uiComponent: "sensor"

    12. **measure_battery_health.json** — `type: "number"`, title "Battery Health", units "%", min 0, max 100, step 0.1, decimals 1

    All capabilities must have: `"getable": true`, `"setable": false`, `"uiComponent": "sensor"`. All titles use `{ "en": "..." }` format.
