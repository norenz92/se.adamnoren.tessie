       const ASLEEP_INTERVAL_MS = 30 * 60 * 1000;     // 30 minutes when asleep

    3. **Implement `pollCycle()` method** — The main polling orchestrator:
       ```
       try:
         1. Call this.client.getStatus(this.vin) to get vehicle status
         2. Map status to vehicle_state_status capability:
            - "awake" -> "Awake"
            - "asleep" -> "Asleep"
            - "waiting_for_sleep" -> "Asleep" (user decision: display as Asleep)
         3. Call this.client.getVehicle(this.vin) to get cached state
         4. Call this.updateCapabilities(state)
         5. Check if battery health is due (Date.now() - lastBatteryHealthFetch > BATTERY_HEALTH_INTERVAL_MS or lastBatteryHealthFetch === 0)
            - If due: call this.fetchBatteryHealth(), update lastBatteryHealthFetch
         6. Reset consecutiveFailures to 0
         7. Call this.setAvailable()
         8. Determine next interval:
            - If status is "asleep" or "waiting_for_sleep" -> ASLEEP_INTERVAL_MS
            - Else if state.charge_state?.charging_state === "Charging" -> CHARGING_INTERVAL_MS
            - Else -> AWAKE_INTERVAL_MS
         9. Call this.scheduleNextPoll(interval)
       catch:
         1. Increment consecutiveFailures
         2. Log error with failure count
         3. If consecutiveFailures >= MAX_CONSECUTIVE_FAILURES:
            - Set vehicle_state_status to "Offline"
            - Call this.setUnavailable('Unable to reach Tessie API')
         4. Keep polling at current interval to detect recovery
       ```
