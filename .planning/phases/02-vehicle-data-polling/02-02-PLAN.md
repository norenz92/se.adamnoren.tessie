Tessie API state response structure (fields used):
```typescript
interface TessieState {
  charge_state: {
    battery_level: number;          // 0-100 percentage
    battery_range: number;          // miles (always)
    charging_state: string;         // "Disconnected"|"Charging"|"Stopped"|"Complete"|"NoPower"
  };
  climate_state: {
    inside_temp: number;            // Celsius float
    outside_temp: number;           // Celsius float
  };
  drive_state: {
    latitude: number;
    longitude: number;
  };
  vehicle_state: {
    locked: boolean;
    odometer: number;               // miles (always)
    tpms_pressure_fl: number;       // bar float (may be null/0 when parked)
    tpms_pressure_fr: number;
    tpms_pressure_rl: number;
    tpms_pressure_rr: number;
    software_update: {
      status: string;               // e.g. "available", ""
      version: string;              // e.g. "2024.26.3.1"
    };
  };
  gui_settings: {
    gui_distance_units: string;     // "km/hr" or "mi/hr"
    gui_temperature_units: string;  // "C" or "F"
    gui_tirepressure_units: string; // "Bar" or "Psi"
  };
}

// Tessie status response:
// { status: "asleep" | "waiting_for_sleep" | "awake" }

// Tessie battery health (filtered by VIN in client):
// { health_percent: number, degradation_percent: number, capacity: number, original_capacity: number }
```

**Device file (`drivers/vehicle/device.ts`):**

Replace the entire VehicleDevice class with:

```
Constants:
  AWAKE_INTERVAL_MS = 60 * 1000        (1 minute)
  CHARGING_INTERVAL_MS = 2 * 60 * 1000 (2 minutes)
  ASLEEP_INTERVAL_MS = 30 * 60 * 1000  (30 minutes)
  BATTERY_HEALTH_INTERVAL_MS = 60 * 60 * 1000 (1 hour)
  MAX_CONSECUTIVE_FAILURES = 3
  MILES_TO_KM = 1.60934
  BAR_TO_PSI = 14.5038

Properties:
  client: TessieClient
  pollTimer: ReturnType<typeof setTimeout> | null
  batteryHealthTimer: ReturnType<typeof setInterval> | null
  consecutiveFailures: number = 0
  isMetric: boolean = true      (default, updated from gui_settings)
  usesPsi: boolean = false      (default, updated from gui_settings)

onInit():
  1. Create TessieClient from stored token
  2. Register locked capability listener (throw "Control not yet available" -- Phase 3)
  3. Migrate capabilities: for each of the 16 capabilities in driver.compose.json, call addCapability if !hasCapability
  4. Do initial data fetch: call getStatus + getVehicle + getBatteryHealth
  5. From first state response, read gui_settings and call setCapabilityOptions to set correct units for measure_range (km or mi), measure_odometer (km or mi), and tire pressures (bar or psi). Store isMetric and usesPsi flags. Only call setCapabilityOptions if units differ from defaults.
  6. Map all capabilities from initial state via updateCapabilities()
  7. Update battery health from initial getBatteryHealth response
  8. Schedule first pollCycle via setTimeout
  9. Schedule batteryHealth refresh via setInterval (hourly)

pollCycle():
  1. try:
    a. Call client.getStatus(vin) -- lightweight, does not wake vehicle
    b. Map status to vehicle_state_status capability: "asleep"/"waiting_for_sleep" -> "Asleep", "awake" -> "Awake"
    c. Call client.getVehicle(vin) -- uses cache by default, safe for sleeping vehicles
    d. Call updateCapabilities(state)
    e. Reset consecutiveFailures = 0
    f. Call setAvailable()
    g. Determine next interval:
       - If status is "asleep" or "waiting_for_sleep" -> ASLEEP_INTERVAL_MS
       - Else if charge_state.charging_state === "Charging" -> CHARGING_INTERVAL_MS
       - Else -> AWAKE_INTERVAL_MS
    h. Schedule next pollCycle via setTimeout (clear previous timer first)
  2. catch:
    a. Increment consecutiveFailures
    b. Log error with failure count
    c. If consecutiveFailures >= MAX_CONSECUTIVE_FAILURES:
       - Set vehicle_state_status to "Offline"
       - Call setUnavailable("Unable to reach Tessie API")
    d. Schedule next poll at current interval (keep trying to recover)

updateCapabilities(state):
  Map all Tessie state fields to Homey capabilities with null guards:
  - charge_state.battery_level -> measure_battery
  - charge_state.battery_range -> measure_range (convert miles->km if isMetric, round to integer)
  - charge_state.charging_state -> charging_status
  - climate_state.inside_temp -> measure_temperature.inside (always Celsius, Homey converts)
  - climate_state.outside_temp -> measure_temperature.outside
  - drive_state.latitude -> measure_latitude
  - drive_state.longitude -> measure_longitude
  - vehicle_state.tpms_pressure_fl/fr/rl/rr -> measure_tire_pressure_fl/fr/rl/rr
    - Skip if value is null or 0 (keeps last known good value on card)
    - Convert bar->psi if usesPsi (multiply by BAR_TO_PSI), round to 1 decimal
  - vehicle_state.odometer -> measure_odometer (convert miles->km if isMetric, round to integer)
  - vehicle_state.software_update -> software_update:
    - If version present: "{status}: {version}" (capitalize status)
    - If no version or empty: "Up to date"
  - vehicle_state.locked -> locked

updateBatteryHealth(healthData):
  If healthData has health_percent, set measure_battery_health to that value.

onDeleted():
  Clear pollTimer (clearTimeout) and batteryHealthTimer (clearInterval). Set both to null.

IMPORTANT: Use setTimeout (not setInterval) for poll scheduling so interval can change adaptively between polls. Use a scheduleNextPoll(ms) helper that clears any existing timeout and sets a new one. Use setInterval for battery health since it runs on a fixed cadence.
```

Use `export =` pattern per project convention. All TypeScript.
