    **TessieClient (lib/tessie-client.ts):**
    Add two new methods to the TessieClient class:

    1. `async command(vin: string, command: string, params?: Record<string, string | number | boolean>): Promise<boolean>` - Builds path as `/${vin}/command/${command}?wait_for_completion=true&{extra_params}`. Uses URLSearchParams to build query string. Calls `this.request(path, 'POST')`. Returns `response.result === true`.

    2. `async wake(vin: string): Promise<boolean>` - Calls `this.request(`/${vin}/wake`, 'POST')`. Returns `response.result === true`.

    The existing `request()` method already supports a `method` parameter, so POST will work. Tessie commands use query params (not request body), so the path-based approach works.

    **Capability JSON files (.homeycompose/capabilities/):**
    Create 9 JSON files following existing capability file patterns (see charging_status.json for reference).

    - `charge_limit.json`: type number, title "Charge Limit", uiComponent "slider", min 50, max 100, step 1, units "%", setable true, getable true

    - `climate_onoff.json`: type boolean, title "Climate", uiComponent "toggle", setable true, getable true
    - `sentry_mode.json`: type boolean, title "Sentry Mode", uiComponent "toggle", setable true, getable true
    - `charge_port.json`: type boolean, title "Charge Port", uiComponent "toggle", setable true, getable true
    - `trunk.json`: type boolean, title "Trunk", uiComponent "toggle", setable true, getable true
    - `frunk.json`: type boolean, title "Frunk", uiComponent "button", setable true, getable false
    - `charging_control.json`: type boolean, title "Charging", uiComponent "toggle", setable true, getable true
