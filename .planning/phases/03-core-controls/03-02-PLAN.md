<!-- Tessie API state fields for new capabilities (from RESEARCH.md) -->
State fields to map in updateCapabilities():
- charge_state.charge_limit_soc -> charge_limit (number, 50-100)
- charge_state.charge_current_request -> charging_amps (number)
- charge_state.charge_current_request_max -> setCapabilityOptions('charging_amps', { max })
- charge_state.charge_port_door_open -> charge_port (boolean)
- charge_state.charging_state -> charging_control (boolean, 'Charging' = true)
- climate_state.is_climate_on -> climate_onoff (boolean)
- climate_state.driver_temp_setting -> target_temperature (number, Celsius)
- vehicle_state.sentry_mode -> sentry_mode (boolean)
- vehicle_state.rt -> trunk (boolean, 0=closed, non-zero=open)
- vehicle_state.ft is NOT mapped (frunk is getable: false, open-only)

<!-- Command mapping for capability listeners -->
Capability -> Tessie command(s):
- locked: true -> 'lock', false -> 'unlock'
- sentry_mode: true -> 'enable_sentry', false -> 'disable_sentry'
- climate_onoff: true -> 'start_climate', false -> 'stop_climate'
- target_temperature: value -> 'set_temperatures' { temperature: value }
- charge_limit: value -> 'set_charge_limit' { percent: value }
- charging_amps: value -> 'set_charging_amps' { amps: value }
- charge_port: true -> 'open_charge_port', false -> 'close_charge_port'
- charging_control: true -> 'start_charging', false -> 'stop_charging'
- trunk: any -> 'activate_rear_trunk' (single toggle command)
- frunk: any -> 'activate_front_trunk' (fire-and-forget)

    2. Add `private async ensureAwake(): Promise<void>`:

       - Check `this.getCapabilityValue('vehicle_state_status')` -- if not 'Asleep', return immediately

    3. Add `private async executeCommand(command: string, params?: Record<string, string | number | boolean>): Promise<void>`:
       - Call `await this.ensureAwake()`
       - `const vin = this.getData().id`
       - `const success = await this.client.command(vin, command, params)`
       - If !success, throw new Error(`Command ${command} failed`)
       - Call `await this.refreshState()` (immediate re-poll per locked decision)
