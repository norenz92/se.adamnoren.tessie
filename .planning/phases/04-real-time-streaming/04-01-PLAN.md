  <behavior>
    - Constructor accepts (vin, token) and stores them
    - connect() creates WebSocket to wss://streaming.tessie.com/{VIN}?access_token={TOKEN}
    - Emits 'connected' on WebSocket open event
    - Emits 'data' with parsed data array when message contains data field
    - Emits 'connectivity' with status string when message contains status field
    - Emits 'disconnected' on WebSocket close event
    - isConnected returns true after open, false after close
    - Schedules reconnect on close with exponential backoff
    - Backoff starts at 1000ms, doubles each attempt, caps at 60000ms
    - Backoff includes 0-30% jitter
    - Backoff resets to 1000ms on successful open
    - destroy() closes WebSocket, clears reconnect timer, sets connected=false
    - destroy() prevents further reconnection attempts
    - Ignores JSON parse errors on malformed messages
  </behavior>
  <action>
    Create `lib/tessie-streamer.ts`:

    1. Import `EventEmitter` from `node:events`.

    2. Class `TessieStreamer extends EventEmitter` with:
       - Private fields: `ws: WebSocket | null`, `vin: string`, `token: string`, `reconnectDelay: number` (initial 1000), `maxReconnectDelay: number` (60000), `reconnectTimer: ReturnType<typeof setTimeout> | null`, `_connected: boolean`, `destroyed: boolean`
       - Constructor(vin, token) — store vin and token, call super()
       - `connect()`: Create `new WebSocket(url)` where url = `wss://streaming.tessie.com/${this.vin}?access_token=${this.token}`. Add event listeners:
         - `open`: set _connected=true, reset reconnectDelay to 1000, emit 'connected'
         - `message`: JSON.parse event.data in try/catch. If msg.data exists, emit 'data' with msg.data and msg.createdAt. If msg.status exists, emit 'connectivity' with msg.status.
         - `close`: set _connected=false, emit 'disconnected', call scheduleReconnect()
         - `error`: no-op (close always follows error)
       - `get isConnected(): boolean` — returns _connected
       - Private `scheduleReconnect()`: If destroyed, return. Calculate jitter = Math.random() * 0.3 * reconnectDelay. Set reconnectTimer = setTimeout(() => connect(), delay + jitter). Double reconnectDelay up to max.
       - `destroy()`: Set destroyed=true. Clear reconnectTimer if set. Close ws if exists (ws.close()). Set _connected=false, ws=null.
