# Project Guidelines

## Language & Build

- **TypeScript** — all source and test files must be `.ts`
- Homey CLI compiles TS to `.homeybuild/` automatically during `homey app run`
- `tsconfig.json` outDir must be `./.homeybuild` (Homey CLI requirement)
- Tests compiled separately via `tsconfig.test.json` to `dist-test/`
- Use `export =` (not `export default`) for Homey CommonJS runtime compatibility
- `app.json` is auto-generated by Homey Compose from `.homeycompose/app.json` + driver compose files

## Project Structure

- `app.ts` — Homey app entry point
- `lib/` — shared modules (e.g. `tessie-client.ts`)
- `drivers/` — Homey device drivers
- `tests/` — test files (`*.test.ts`), run with `node --test`
- `.homeybuild/` — compiled output (gitignored, managed by Homey CLI)
- `.homeycompose/` — Homey Compose source files
- `.planning/` — GSD planning artifacts
