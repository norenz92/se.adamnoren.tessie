# Tessie

**Tessie for Homey** brings the power of Tessie to your smart home, allowing you to monitor and control your Tesla through Homey. This integration unlocks a seamless experience to automate Tesla-related tasks, create powerful flows, and access real-time vehicle data.

## Getting Started
### Prerequisites
To use the Tessie Integration for Homey, you will need:

- #### A Tessie Account
[Sign up at Tessie](https://share.tessie.com/1oPgpu3hfMb) if you don't already have an account.

- #### A Tessie API Key

Log in to your Tessie account and [setup an API key](https://dash.tessie.com/settings/api). Enter the generated API key in the app settings in Homey and save.

Add a Tessie device in Homey. It should find your connected vehicles.
